# GoldNewsAI v5

三周期黄金市场信息整理工具。

## v5 变化
- 1小时 / 1天 / 1周三个风向盘。
- 财联社公开网页新闻抓取。
- 公开 XAU/USD 现货数据 + 48小时盘中序列 + 日线历史。
- 本地规则引擎：事件类别、方向、强度、周期权重、新闻去重、行情动量融合。
- 无需用户填写 Gemini API Key。
- GitHub Actions 可在云端自动构建 `app-debug.apk`。

## 数据源
新闻：财联社公开网页。
黄金行情：XAUS 公共数据接口。其公开说明称 XAU/USD 数据无需 API key，适合个人项目使用；价格为参考性现货价格。

## 重要限制
- 这是信息整理/研究展示，不是投资建议，不提供买卖指令。
- 新闻网页结构变化可能导致抓取失败。正式商业版本应使用获得授权的新闻/行情数据服务。
- 公开行情源可能延迟、缓存或暂时不可用。
- 当前“智能分析”是端侧确定性分析，不是云端生成式大模型。

## 手机编译
1. 创建 GitHub 仓库。
2. 将本目录内容上传到仓库根目录，不要再套一层 `project`。
3. 打开 Actions。
4. 选择 Build GoldNewsAI APK。
5. Run workflow。
6. 成功后下载 Artifacts 中的 `GoldNewsAI-v5-debug-apk`。
